✦ NovaForce Games — Gizlilik Politikası

Son güncelleme: 22 Kasım 2026 · PULSE DRIFT (Web ve Android test projesi)

Türkçe

PULSE DRIFT'in web oyunu hesap oluşturmayı gerektirmez. En yüksek skorunuzu ve ses tercihinizi tarayıcınızın yerel depolamasında (localStorage) saklarız. Bunlar otomatik olarak kendi sunucumuza gönderilmez. Tarayıcı verilerini silerek kayıtları kaldırabilirsiniz.

Oyun GitHub Pages üzerinden sunulur. GitHub, site erişimiyle ilgili IP adresi ve istek günlükleri gibi teknik verileri kendi hizmet politikalarına göre işleyebilir. Ayrıntılar için GitHub gizlilik bildirimi.

Web sürümündeki “Free Test Continue” özelliği reklam göstermeden bir can verir; bu aşamada oyunda gelir getiren reklam yoktur.

Android geliştirme/test sürümünde Google Mobile Ads (AdMob) test reklamları ve Google User Messaging Platform (UMP) kullanılır. Bu Google bileşenleri; reklam göstermek, performans ölçmek, dolandırıcılığı engellemek ve izinleri yönetmek için cihaz tanımlayıcıları, IP adresi, reklam etkileşimleri ve izin tercihlerine ilişkin veriler işleyebilir. Ayrıntılar: Google Gizlilik Politikası.

Çocuklara yönelik bir oyun olarak özel olarak tasarlanmamıştır. Google Play'de yayınlanmadan önce veri güvenliği açıklamaları, yaş grubu, reklam ayarları ve gerekiyorsa izin mesajları ayrıca tamamlanacaktır.

İletişim: NovaForce Games GitHub proje bildirimleri.

English

The PULSE DRIFT web game does not require an account. High scores and audio settings are stored locally in your browser. Our game code does not upload those values to a server. Clear browser site data to erase them.

The site is hosted on GitHub Pages. GitHub may process technical requests and access information according to its privacy statement.

The web version's free test continue does not display advertising or generate revenue. The Android developer/test build uses Google's Mobile Ads SDK test ads and User Messaging Platform. Google may process device identifiers, IP addresses, ad interactions and consent choices for serving ads, measurement, fraud prevention and privacy management; see Google Privacy Policy.

Before a public Android launch, the Play Store Data safety form, intended audience, ad account setup, and required consent options must be configured and reviewed.

Contact: NovaForce Games project issues on GitHub.
